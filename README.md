# QJams

**QJams.  Practice.  Watch.  Loop.  Perfect.**
The video-synced jamming and practice DAW with 12-track recorder, full track editing and real time gain staging. Built for musicians on Linux. I started it started as a Quad Cortex practice tool. It Evolved. Connect anything!

Plug in your audio interface and start jamming. Combine a live 12-track recorder with perfectly synced video capture so you can look back at exactly how you nailed that take. Built natively in C for Linux for maximum performance and zero latency.

Visit https://sites.google.com/view/qjams/home for more info.
